## 📘 Conceitos que estou aprendendo

### 🧠 O que é uma variável?
Uma variável é um espaço na memória onde podemos guardar valores. No JavaScript usamos palavras como `let`, `const` ou `var` para declarar variáveis.

Exemplo:
```javascript
let nome = "José";
const idade = 37;
```

### 🔁 O que são estruturas de repetição?
São formas de repetir comandos várias vezes, como for, while.

Exemplo:
```javascript
for (let i = 0; i < 5; i++) {
  console.log("Repetição número " + i);
}
```
### ⚙️ O que é uma função?
Função é um bloco de código reutilizável que executa uma tarefa.
Exemplo:
```javascript
function saudacao(nome) {
  return "Olá, " + nome + "!";
}
```
### 📦 O que é um array?
Um array é uma lista de valores em uma única variável. Cada item tem um índice (posição), que começa no zero.

Exemplo:
```javascript
const frutas = ["maçã", "banana", "uva"];
console.log(frutas[0]); // "maçã"
console.log(frutas.length); // 3 (quantidade de itens)
```
